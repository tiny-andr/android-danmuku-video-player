# 手机播放交互检查与改进计划

## 参考播放器

- [Just Player](https://github.com/moneytoo/Player)：左侧滑动调亮度、右侧滑动调媒体音量，横向滑动和双击快进退，以及适应/裁剪、触摸锁、播放速度、音频焦点、耳机断开暂停和画中画。
- [VLC 手势说明](https://docs.videolan.me/vlc-user/ios/3.X/en/basic/playbackgestures.html)：左侧亮度、右侧音量，横向滑动和左右双击快进退，默认每次跳转 10 秒。该页面介绍的是 iOS，只作为交互参考，不能用来判断 Android 接口的行为。

## 此前已完成

以下是上一轮已经实现并验证的功能，不代表后面的新增目标也已完成。

- **左右滑动调节**：仅在播放画面内部识别上下滑动，避开上下控制栏和 Android 导航边缘。移动超过 12 个 CSS 像素后判断是否为垂直手势，不拦截横向滑动和多指操作；Artplayer 原有控件继续处理各自的触摸事件。
- **亮度与媒体音量**：左半屏只调当前播放窗口的亮度，范围为 5%–100%，不修改系统亮度设置；右半屏调 Android 媒体音量，受系统最小值和最大值限制。画面中央显示百分比，松手后消失；离开播放页恢复系统亮度。
- **自动方向策略**：使用遵守用户设置的方向策略，不再用 `fullSensor` 绕过系统旋转锁。关闭系统自动旋转时，播放保持当前方向；开启时，视频宽 > 高使用横屏，宽 ≤ 高使用竖屏。播放期间监听系统开关，但不主动替用户开启自动旋转。部分 Android 大屏设备的厂商策略可能忽略应用请求的方向。
- **统一加载页**：选中视频后立即显示打开/缓冲页面，不在读取视频信息时露出首页。当前片源有可解码画面后才撤掉加载页；提供超时、重试和返回原目录入口。换片或取消后，旧文件信息与附件请求的迟到结果会被丢弃。
- **弹幕不抢先提示**：自动加载弹幕只更新播放器信息，不在视频播放前连续弹出成功提示。剧集列表、弹幕等附件不再阻塞视频起播，附件失败也不会把已经能播的视频变成加载失败。
- **退出释放资源**：离开播放页时暂停并移除媒体源，释放网络响应，停用手势，恢复方向策略与亮度，并作废未完成的视频信息和附件任务。
- **默认弹幕字号**：APK 默认字号为 18 个 CSS 像素；用户已明确保存的插件设置仍优先使用。
- **网络连接隔离**：目录/文件信息与媒体播放使用独立且持续复用的连接池。连接失效时同时核对对象身份和配置版本；取消响应只关闭自身文件句柄，真正断开的会话才被淘汰，明确的临时传输错误最多重试一次。

## 本轮已完成（2026-11-16）

- 顶部增加“横屏／竖屏”按钮，随播放控件一起显示和隐藏。点击是一次性的手动方向覆盖：不修改系统自动旋转开关，退出播放或切换影片时清除覆盖。
- 播放控件改为高不透明黑色背景；顶部返回、转屏、信息、播放列表按钮与视频/弹幕分离显示。
- 移除顶部重复的“弹”按钮。原弹幕插件的开关和设置入口挂回底部播放控制栏，并在竖屏、横屏都保留可点击热区；设置面板使用高对比深色卡片。
- 默认弹幕速度为“适中”（9 秒穿过画面）。旧版保存的 20 秒默认值只迁移一次，用户其他设置继续保留。

## 此轮真机验证

- 关闭系统自动旋转并锁竖屏：顶部“横屏”按钮可主动切到横屏，系统开关仍保持关闭；再次点击可切回竖屏。
- 竖屏控制栏：弹幕开关和设置入口均命中；设置面板不超出屏幕。横屏同样通过。
- 播放控件显示时顶部背景为 `rgba(0,0,0,.94)`，底部控件为黑色渐变；控件隐藏时顶部不接收点击、底栏透明度接近 0。
- 实测弹幕速度为 9、字号为 18px；退出播放恢复系统竖屏。

## 本轮五项基础操作（已完成）

- **锁定（防误触）**：播放控制栏增加“锁定”入口，不会熄屏或锁住手机。开启后拦截画面的点击、双击、滑动和控制栏操作；提示及“解锁”按钮约 2 秒后隐藏。随后轻点画面只唤出解锁按钮，约 2 秒后再次隐藏；滑动和隐藏按钮位置的首次触摸不会直接解锁。点可见“解锁”按钮或使用系统返回键可恢复操作。
- **断点续播**：按稳定文件路径记录播放位置，不保存临时媒体 URL；低于 5 秒、接近结尾、过期 30 天或视频时长变化时自动清理。重新打开时弹出“继续播放／从头播放／取消”，不会静默跳播。
- **音频焦点与耳机断开暂停**：WebView/Chromium 是系统音频焦点唯一所有者；原生桥只管理播放会话、耳机断开和后台生命周期，不重复申请焦点。失去焦点、耳机断开或切后台会暂停，不自动恢复；用户再次点击播放才继续。
- **双击快进退**：画面左侧双击后退 10 秒，右侧双击前进 10 秒；中间区域不触发。与亮度、音量垂直滑动、控制栏和触摸锁互斥。
- **适应／裁剪**：控制栏悬浮按钮在“适应”和“裁剪”之间切换，均保持视频比例，不拉伸画面。

## 本轮验证（2026-11-16）

- 真实设备五项回归通过：双击时间从约 1 秒前进到 11 秒，再后退到约 1 秒；锁屏后跳转与亮度/音量手势均无效，解锁后恢复。
- 续播实测保存 8 秒，重开弹出“上次看到 0:08 / 0:20”，继续播放从 8 秒开始；选择从头播放从 0 秒开始。
- 适应/裁剪均保持视频比例；后台切换已真机验证，耳机断开事件的前端暂停回调与原生会话状态已覆盖。物理耳机拔插未在此轮执行。
- 独立媒体前台服务真实抢占 Android 音频焦点后，播放器暂停；服务释放焦点后播放器保持暂停，不自动抢播；用户再次点播放可继续。测试包和临时服务已停止并清理。系统日志确认焦点由 Chromium `AudioFocusDelegate` 持有；原生桥不再重复申请焦点，只管理会话许可、耳机断开和后台生命周期。


## 播放常亮设置（2026-11-16）

- 设置页新增“播放时保持屏幕亮屏”，默认勾选。旧设置缺少该字段时默认开启，不重置音轨和字幕偏好；用户主动取消后记住选择，重启后仍有效。
- 常亮仅限前台播放会话；暂停时留在播放页仍保持亮屏，退出播放、加载失败或切后台后释放。关闭选项后遵循系统熄屏时间，不修改系统设置，也不阻止用户按电源键熄屏。
- 原生窗口与 WebView 子视图的常亮申请统一受此选项控制，避免 Chromium 播放视频时绕过用户选择。
- 已验证：设置迁移、持久化、真实视频播放时开启/关闭窗口常亮标志、关闭后暂停再播放、后台释放、退出播放释放；设置页截图已检查。存储检查 6 组与断点记录检查 12 组通过。本轮没有等待系统熄屏倒计时做长时间测试。

## 仍可继续补齐

以下是尚未实现的后续建议，不是本轮已完成内容。

| 优先级 | 功能 | 当前情况与建议 |
| --- | --- | --- |
| Done | Manual external subtitles and danmaku | Select arbitrary local/network directories and filenames without changing the video origin. |
| Done | Subtitle timing and style | Per-video delay, size/color/outline and explicit-save language preferences. ASS/SSA text compatibility only. |
| Excluded | Hold-to-speed | Explicitly declined by the user; keep the existing speed menu only. |
| Excluded | Picture-in-picture | Explicitly cancelled by the user. |
| Deferred | Background playback | Keep background-pause policy; no native media service added in this batch. |
| Deferred | Additional audio codecs and embedded subtitles | Native audio processing, embedded extraction and PGS remain outside this batch. |

本计划不涉及无关的播放器核心重写，也不增加对远程存储的写入操作。

## 此前真实验证记录（2026-11-16）

以下数据来自上一轮测试，**不是本轮新增目标的验收结果**。

- 完整 arm64 调试 APK 构建成功，并覆盖安装到现有应用，没有重置已保存的网络连接。
- 14 项 Kotlin 网络测试通过：9 项连接生命周期/并发测试，5 项路径/字节范围测试。
- 通过真实 CDP 触摸事件，窗口亮度从 0.247 调到 0.733，媒体音量从 3 调到 10，系统最大音量为 15。退出后恢复系统亮度；回归工具恢复了原音量。
- 同一条已保存的 SMB 影片连续进行三轮“打开、拖动进度、退出”，随即读取根目录，均返回 81 项，耗时分别为 77／98／52 毫秒。测试工具没有读取账号密码。
- 开启自动旋转时，1280×720 视频使用 931×415 视口；生成的 360×640 竖屏片和 360×360 方形片均使用 415×931 视口。关闭系统自动旋转后，宽屏视频仍保持 415×931。测试工具恢复了原旋转设置。
- 延迟读取文件信息的测试确认：打开视频立即隐藏首页；取消后回到文件选择器、移除媒体源，并忽略延迟完成的旧结果。文件不存在时保留带重试入口的加载失败页，不闪回首页。
- 实际读取插件默认字号为 18，自动弹幕加载没有弹出成功提示。
- Android 系统截图确认竖屏视频画面正常。这台设备的 CDP 截图不包含硬件合成的视频层，因此不能仅凭 CDP 截图的黑色区域判断视频黑屏。
